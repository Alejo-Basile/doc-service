## Decisiones relevantes de la semana

- **El PDF nunca pasa por doc-service ni por Traefik.** La API emite URL prefirmada POST de MinIO
  firmada contra el host público `s3.dominio` (detalle en SPEC §5.1 y ADR de host S3).
- **Transiciones condicionales estrictas:** todo cambio de estado es
  `updateOne({_id, status: esperado}, ...)`. Nunca `upsert` ciego.
- **Sin campo `attempts` en el documento:** los reintentos se miden con el delivery count de
  `XPENDING` de Redis Streams (SPEC §5.4).
- **Tags `bson` directamente en el dominio:** decisión documentada en `mongo-schema.md` §5 —
  la capa domain no importa el driver; los tags son solo strings en structs.

## Decisión de versión de Go

La versión canónica del repo es **go 1.24** (`go.mod` → `go 1.24`), igual que S0-A en `main`.
La rama F1/F2 se adelantó declarando 1.25 porque `mongo-driver v2.9.1` lo exige; se resolvió
pinnando `mongo-driver v2.8.2` (requiere go 1.19) y bajando las `golang.org/x/*` a versiones
compatibles. Todo el equipo compila localmente con el SDK 1.24.4 y CI usa `go-version-file: go.mod`,
con lo cual el repo queda con una única fuente de verdad.
